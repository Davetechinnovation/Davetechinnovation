### 👨‍💻 About Me

I'm **Udoka Dandave Chibuzor**, a self-taught Full Stack Developer from **Nigeria 🇳🇬** with 3 years of experience building real-world web and mobile applications.

I don't just write code — I build products. From streaming platforms and crypto apps to WhatsApp bots and transport dashboards, I ship things that work and solve real problems.

- 🔭 Currently building and improving projects under **Dandy-Hub**
